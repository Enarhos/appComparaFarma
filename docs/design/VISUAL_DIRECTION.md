**ID:** VISUAL-001

**Estado:** ACTIVE

**Versión:** 1.0

**Dominio:** Design

**Tipo:** Dirección de Diseño

---

# 1. Propósito

Este documento define la dirección visual oficial de ComparaFarma.

Su objetivo es garantizar que todas las decisiones relacionadas con la apariencia de la plataforma respondan a una misma visión de diseño.

No define componentes.

No define colores específicos.

No define tipografías.

No reemplaza el Design System.

Su función es orientar todas las decisiones visuales posteriores.

---

# 2. Objetivo

Construir una identidad visual coherente con la estrategia de ComparaFarma como Plataforma de Inteligencia Farmacéutica.

La apariencia de la plataforma debe comunicar confianza, claridad e inteligencia antes que el dominio en el que opera.

---

# 3. Posicionamiento Visual

ComparaFarma no debe percibirse como una farmacia digital.

Debe percibirse como una empresa tecnológica especializada en información farmacéutica.

El usuario debe sentir que está utilizando una plataforma de inteligencia y análisis, no un canal de venta.

---

# 4. Principios Visuales

Toda decisión visual deberá respetar los siguientes principios.

## Claridad

La información siempre tiene prioridad sobre la decoración.

---

## Confianza

El diseño debe transmitir estabilidad y profesionalismo.

---

## Neutralidad

La interfaz nunca favorecerá visualmente a una farmacia específica.

---

## Simplicidad

Reducir complejidad antes que añadir elementos.

---

## Precisión

Cada elemento debe tener una función clara.

---

## Accesibilidad

El diseño debe ser comprensible para cualquier persona.

---

## Consistencia

Todos los productos deberán compartir el mismo lenguaje visual.

---

# 5. Personalidad Visual

La identidad de ComparaFarma deberá percibirse como:

- Inteligente
- Transparente
- Moderna
- Cercana
- Serena

---

# 6. Anti-personalidad

La marca nunca deberá parecer:

- Una farmacia
- Un marketplace
- Un supermercado
- Una clínica
- Un sitio de promociones

---

# 7. Referencias

Las siguientes empresas representan principios de diseño que inspiran el lenguaje visual de ComparaFarma.

No constituyen referencias estéticas para copiar.

Representan únicamente principios.

| Empresa | Principio |
|----------|-----------|
| Apple | Simplicidad |
| Stripe | Calidad |
| Linear | Precisión |
| Perplexity | Claridad |
| Notion | Organización |

---

# 8. Lenguaje Visual

La interfaz deberá privilegiar:

- espacios amplios;
- jerarquía tipográfica clara;
- pocos colores;
- uso cuidadoso del contraste;
- iconografía simple;
- baja carga visual.

---

# 9. Exclusiones

No forman parte de este documento:

- Color System
- Typography System
- Iconography System
- Motion System
- Component Library
- Design Tokens

Cada uno será definido en su documento correspondiente.

---

# 10. Criterios de Aceptación

Toda decisión visual futura deberá poder justificarse utilizando este documento.

Si una propuesta contradice alguno de estos principios, deberá rechazarse o modificarse antes de su implementación.

---

# Estado

Este documento constituye la dirección visual oficial de ComparaFarma.

Toda evolución posterior deberá mantener coherencia con los principios aquí definidos.
