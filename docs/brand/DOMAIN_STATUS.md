# Estado del Dominio

El dominio **Brand** se considera arquitectónicamente completo.

La identidad de ComparaFarma ha sido definida mediante la arquitectura documental oficial y constituye la referencia para toda implementación visual futura.

A partir de este momento el dominio entra en estado **Managed**.

---

# Objetivo

Garantizar la estabilidad de la identidad de marca.

Evitar la creación de documentación redundante.

Favorecer la implementación consistente de la marca en todos los productos.

# Gobernanza

La gobernanza del dominio se considera finalizada.

Las futuras decisiones relacionadas con la marca deberán implementarse utilizando la arquitectura existente.

No deberán crearse nuevos documentos de gobernanza salvo que exista un cambio estratégico que modifique la identidad de ComparaFarma.

---

# Implementación

Los siguientes entregables pertenecen a la etapa de implementación y no modifican la arquitectura:

- Brand Book
- Assets oficiales
- Recursos gráficos
- Componentes visuales
- Material corporativo
- Recursos para marketing
- Aplicaciones de marca

---

# Próximos Programas

La evolución del proyecto continúa mediante los programas:

- WEB
- Mobile
- Operations
- Growth
- Intelligence

El dominio Brand actuará como referencia para todos ellos.

---

# Criterios de Reapertura

El dominio solo podrá reabrirse cuando exista alguno de los siguientes escenarios:

- Cambio de posicionamiento estratégico.
- Cambio de arquitectura de marca.
- Incorporación de nuevas marcas corporativas.
- Rebranding oficial.
- Expansión internacional que requiera adaptar la identidad.

Fuera de estos casos, toda evolución deberá realizarse mediante implementación y nunca mediante nueva gobernanza.
