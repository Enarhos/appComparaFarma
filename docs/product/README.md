# Product Documentation

Esta carpeta contiene toda la documentación relacionada con el producto ComparaFarma.

El objetivo es que cualquier persona o IA pueda comprender el producto sin necesidad de revisar el código fuente.

## Documentos

| Documento | Descripción |
|------------|-------------|
| VISION | Propósito y visión del producto |
| PRODUCT_PRINCIPLES | Principios que guían el desarrollo |
| ROADMAP | Plan de evolución |
| BACKLOG_PRODUCT | Funcionalidades |
| BACKLOG_TECH | Mejoras técnicas |
| KPIS | Indicadores |
| RISKS | Riesgos del producto |
| RELEASES | Historial de versiones |
| IDEAS | Ideas futuras |

Toda funcionalidad nueva debe existir primero en el backlog antes de implementarse.
