# ACTA DE SESIÓN

## ComparaFarma

### Fecha: 05 de agosto de 2026

---

# 1. Objetivo de la sesión

Continuar la consolidación de la Arquitectura Empresarial y la Arquitectura de Marca, cerrar la fase documental estratégica del proyecto y definir la transición hacia la etapa de ejecución y lanzamiento de ComparaFarma.

---

# 2. Principales acuerdos

## 2.1 Arquitectura de Marca

Se revisó y aprobó la versión de `BRAND_ARCHITECTURE.md`.

Se acordó oficialmente que:

* ComparaFarma adopta una arquitectura **Branded House**.
* La marca principal es **ComparaFarma**.
* La aplicación móvil, la plataforma web y los futuros servicios forman parte de una única plataforma de Inteligencia Farmacéutica.
* No se crearán submarcas en esta etapa del proyecto.

---

## 2.2 Arquitectura de Diseño

Se dio por terminada la primera fase de Arquitectura de Diseño.

Se consideran consolidados los siguientes documentos:

* BRAND_AUDIT.md
* BRAND_FOUNDATIONS.md
* VISUAL_IDENTITY.md
* DESIGN_CONCEPT.md
* BRAND_ARCHITECTURE.md

Se acordó que estos documentos pasan a ser la referencia oficial para todas las futuras decisiones de identidad visual.

---

## 2.3 Dominio Design

Se aprobó la creación del dominio:

```
docs/design/
```

Como espacio oficial para documentar:

* exploraciones creativas
* decisiones de diseño
* activos gráficos
* evolución de la identidad visual
* iteraciones
* descartes

Se definió claramente la separación entre:

**Brand**

Define la identidad.

**Design**

Materializa la identidad.

---

## 2.4 Exploración Visual

Se inició oficialmente el proceso de exploración visual de la marca.

Se trabajó sobre tres familias conceptuales:

* Brújula
* Ruta / Mapa
* Constelación

Posteriormente se profundizó en la familia:

**Orientación / Brújula**

No se aprobó ninguna solución gráfica.

Se acordó continuar utilizando un proceso iterativo de exploración antes de diseñar el logotipo definitivo.

---

## 2.5 Gobierno del Programa

Se identificó la necesidad de separar definitivamente la gestión documental de la gestión del programa.

Se aprobó la creación del dominio:

```
docs/program/
```

Como centro de gobierno operativo del proyecto.

---

## 2.6 Program Management System

Se diseñó la estructura inicial del dominio:

```
docs/program/

README.md

PROGRAM_BOARD.md

MASTER_BACKLOG.md

CURRENT_SPRINT.md

ROADMAP.md

MILESTONES.md

RISKS.md

DECISION_QUEUE.md

DONE.md
```

El objetivo será utilizar este dominio como tablero de control oficial del programa.

---

## 2.7 Memoria Histórica

Se revisó el documento:

```
DONE.md
```

Se concluyó que:

* constituye la memoria histórica oficial del programa;
* complementa, pero no reemplaza,
  `docs/product/DECISION_LOG.md`;
* registra la evolución completa del proyecto a través de Enterprise, Brand, Design y Program.

Se propusieron mejoras futuras:

* clasificación por Workstream;
* clasificación por Impacto;
* referencias cruzadas;
* identificación de Major Milestones.

Estas mejoras quedaron registradas para una futura versión.

---

# 3. Cambio de foco estratégico

Durante la sesión se acordó formalmente que la fase de construcción de fundamentos puede considerarse prácticamente concluida.

El foco del proyecto cambia desde:

**Construcción de Arquitectura**

hacia:

**Ejecución y Lanzamiento.**

Se definieron los siguientes grandes programas de trabajo.

## Programa 1

Production Release

Objetivo:

Publicar ComparaFarma en Producción.

## Programa 2

Plataforma

Objetivo:

Continuar la evolución de la Plataforma de Inteligencia Farmacéutica.

## Programa 3

Modelo Comercial

Objetivo:

Consolidar la estrategia de monetización y crecimiento.

## Programa 4

Growth

Objetivo:

Adquisición de usuarios y posicionamiento.

# 6. Próxima sesión

La próxima sesión tendrá como objetivo principal iniciar formalmente la Fase 2 del proyecto.

Los primeros trabajos estarán orientados a:

* cierre oficial de la Fase 1;
* inicio del Sprint Production Release 1.0;
* definición del sistema visual definitivo;
* construcción de los activos para Google Play;
* planificación del lanzamiento a Producción.

---

# 7. Conclusión

La sesión marca un hito relevante en la evolución de ComparaFarma.

Se considera concluida la etapa de definición de los fundamentos estratégicos del proyecto, quedando establecida una arquitectura empresarial, documental, de marca, de diseño y de gobierno suficientemente madura para soportar la siguiente etapa.

A partir de este punto, el programa entra en una nueva fase centrada en la ejecución, el lanzamiento del producto y la validación en el mercado, utilizando el dominio `docs/program/` como centro de gobierno operativo y el marco documental construido durante las sesiones anteriores como fuente oficial para todas las decisiones futuras.
