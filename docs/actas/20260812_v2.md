5. Hallazgo importante

Durante la validación apareció un comportamiento inesperado en:

Recuperación de contraseña.

Investigación

Claude encontró la causa exacta.

No era un bug del código.

Era una limitación de Supabase.

Evidencia

El Preview usa:

*.mariolillo-1620s-projects.vercel.app

Pero Supabase solo acepta:

https://app-compara-farma-web.vercel.app/auth/callback

Como Redirect URL autorizada.

Resultado

El Preview pierde:

/auth/callback

y aterriza en Home con:

?code=...
Decisión

Este comportamiento quedó clasificado como:

Validation Environment Limitation

No como bug.

No requiere Hotfix.

No requiere modificación del Sprint.

La validación completa deberá ejecutarse una vez que el código esté desplegado en Producción o en un dominio autorizado.
